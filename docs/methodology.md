# Методика нагрузочного и стресс-тестирования

## Цель

Проверить поведение веб-сервиса при заданной и повышенной нагрузке: оценить время ответа, пропускную способность и долю ошибочных запросов.

## Load testing

Нагрузочное тестирование проверяет, выдерживает ли система ожидаемую рабочую нагрузку.

Пример параметров:

- 13 виртуальных пользователей;
- 260 запросов в минуту;
- ramp-up: 13 секунд;
- критерии успешности: среднее время ответа в пределах требования и 0% ошибок.

Основные метрики:

- average response time;
- min / max response time;
- p90 / p95 latency;
- throughput;
- error rate;
- HTTP response codes.

## Stress testing

Стресс-тестирование выполняется с постепенным увеличением нагрузки. Цель — найти точку, после которой система начинает работать нестабильно.

Пример признаков перегрузки:

- рост response time;
- рост error rate;
- появление HTTP 500;
- появление HTTP 503 Service Unavailable.

## Анализ результатов

Результаты JMeter сохраняются в `.jtl`/`.csv`, после чего анализируются Python-скриптом. Это позволяет быстро получить сводку и построить графики без ручной обработки в интерфейсе JMeter.
